# 态度与状态

酒馆助手脚本：手动记录 user 的体力、心情，以及 user 对多个角色的单向好感、印象和可选备注。记录随生成临时注入给 AI，方便它把握 user 的表现。

当前功能版本：**v8.2**。提供两种展示，共用同一份数据和交给 AI 的内容。

- **悬浮球**：点击后贴着球淡入缩放展开，拖球时面板跟随，再点球收起。
- **快捷窗口**：独立可拖小窗，拖动顶部移动，右上角 × 保存并关闭。

## 安装

1. 下载 [链接加载版 install.json](https://raw.githubusercontent.com/gqing714-lang/st-attitude-state/main/install.json)。
2. 在酒馆助手的脚本库中导入这个 JSON 文件并启用。已有旧版时覆盖导入，只启用一个版本。
3. 酒馆快捷栏会有两个按钮：**态度与状态**打开面板；**切换显示方式**切换展示并记住选择。

快捷窗口与悬浮球各自记住位置。快捷窗口和贴球页面可以越过屏幕边缘，悬浮球始终留在屏幕内；切换显示方式后，快捷窗口复位居中。

已经装有结合版，也可以在脚本编辑器中把代码内容换为这一行，保留原有按钮设置：

```js
await import('https://cdn.jsdelivr.net/gh/gqing714-lang/st-attitude-state@main/index.js?reload=' + Date.now());
```

入口会用酒馆助手的 `appendInexistentScriptButtons` 补齐缺少的两个按钮，已有按钮的显示设置会保留。推荐导入 `install.json`，它还包含加载失败时的中文提示。

## 更新

维护者更新仓库的 `main/index.js` 后，使用者在**刷新酒馆页面或重新启用脚本时**检查更新。加载器每次带上新的时间参数，避开浏览器对旧文件的长期缓存。正在运行的脚本会继续使用已加载版本，更新时也保留原有聊天记录。

链接指向 `main` 分支。根据 [jsDelivr 缓存说明](https://github.com/jsdelivr/jsdelivr#caching)，分支链接存在缓存，更新可能延迟（文档标注 12 小时）；上传完成并不代表所有人立即获得新版本。

联网加载失败时会提示检查网络；需要离线使用时，下载并导入 [offline.json](https://raw.githubusercontent.com/gqing714-lang/st-attitude-state/main/offline.json)。离线版固定为 v8.2，后续更新需重新导入对应文件。切换在线版与离线版时只启用其中一个。

## 美化适配与拖动

- 滑块沿用当前美化对普通拉条的样式；输入框、角色选择和按钮接入酒馆通用控件样式，字体继承酒馆页面。脚本不内置指定美化。
- 浮窗、贴球页面和悬浮球取消背景磨砂，保留主题底色、边框、黑色 15% 阴影与展开动效。
- 点击本面板不会顺带收起酒馆已经展开的工具栏。
- 拖动按每帧一次合并绘制，不使用常驻轮询或页面观察器；关闭脚本时清理临时状态与事件监听。

## 保存与 AI 读取

- 角色记录、体力和心情保存在当前聊天的酒馆变量中，使用此前版本相同的字段；显示偏好和位置保存在当前浏览器。
- 编辑后自动保存，收起、关窗、切换展示也会保存。已删除角色与清空备注的保存修复保留。
- 角色栏显示 **AI读取** 时，当前角色的记录会交给 AI；点一下变为 **仅保存** 后，记录仍会保留，但 AI 不读取。这个开关只控制当前选中的角色。
- 好感始终表示 **user 对对应角色**的单向态度；角色不直接知晓数值。空备注省略。
- 使用固定 ID 的临时提示词，只保留最新内容；不会把每次注入追加到聊天历史。
- 关闭脚本会清理面板、悬浮球、事件监听和当前临时注入；已保存的记录保留。

## 文件与隐私

`index.js` 是可读的完整运行代码；`install.json` 是小型联网加载器；`offline.json` 是完整离线安装文件。仓库只包含程序与说明，导出数据为空。

脚本不会把聊天记录、填写的内容或 API 密钥上传到 GitHub/jsDelivr；联网加载器仅向 CDN 请求程序文件。加载后，用户填写的内容按脚本功能进入酒馆本轮发送给模型的提示词。在线版会执行本仓库未来更新的代码，请从信任的维护者处安装。

验证环境为 Chromium 手机视口模拟，覆盖 320 / 360 / 390 像素竖屏及横屏；实际表现也会受酒馆助手版本、主题与网络影响。
